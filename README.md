##  Sobre o Projeto

O **Fogo & Brasa Steakhouse** é um projeto web conceitual de landing page desenvolvido para restaurantes de alto padrão focados em carnes nobres, maturação a seco (*Dry Aged*) e cortes especiais (como Tomahawk, Chorizo e Wagyu). O design foi pensado para transmitir sofisticação, conforto e tradição, contando com seções dinâmicas de reservas, vitrine de cortes, combos exclusivos e prova social.

---

##  Tecnologias Utilizadas

Este projeto foi construído com tecnologias modernas e leves, mantendo alta performance e facilidade de manutenção:

* **HTML5** — Estruturação semântica e acessível da página.
* **CSS3 / Tailwind CSS (v4)** — Estilização avançada com foco em design responsivo e paleta de cores personalizada (*Dark Meat*, *Accent Gold*, *Blood Red*).
* **JavaScript (ES6+)** — Interatividade para simulação de reservas rápidas, manipulação do DOM e envio de formulários de newsletter.
